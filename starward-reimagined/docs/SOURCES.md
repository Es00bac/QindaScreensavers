# Dependency and API references

The artwork and implementation in this package were authored for this project.
External technical references checked during development:

- SDL2 OpenGL context creation:
  https://wiki.libsdl.org/SDL2/SDL_GL_CreateContext
- SDL2 context attributes:
  https://wiki.libsdl.org/SDL2/SDL_GL_SetAttribute
  https://wiki.libsdl.org/SDL2/SDL_GLattr
- Khronos OpenGL registry and reference pages:
  https://registry.khronos.org/OpenGL/
  https://registry.khronos.org/OpenGL-Refpages/
- Gentoo SDL2 package and backend/OpenGL USE flags:
  https://packages.gentoo.org/packages/media-libs/libsdl2
- Gentoo Cairo package:
  https://packages.gentoo.org/packages/x11-libs/cairo
- Gentoo GLVND package:
  https://packages.gentoo.org/packages/media-libs/libglvnd

Links identify API/package documentation, not a source of art or an endorsement of
this screensaver. No library binaries, external art packs or fonts are bundled.
The local telemetry parser originated in the earlier GPL-3.0-or-later Starward
prototype from this conversation. The 3D model, material and rendering systems are
new in this revision.
