# Technical references and provenance

The code in this package is locally authored, built on the GPL-3.0-or-later
Prism Circuit renderer and eight-character models supplied earlier in this
conversation. That source package was inspected directly, not reconstructed from
the generated concept image. The concept image is not a runtime asset.

Primary API references checked September 19, 2026:

* SDL2 GL context attributes: `https://wiki.libsdl.org/SDL2/SDL_GL_SetAttribute`
* Actual GL context attribute queries: `https://wiki.libsdl.org/SDL2/SDL_GL_GetAttribute`
* SDL2 window/fullscreen behavior: `https://wiki.libsdl.org/SDL2/SDL_SetWindowFullscreen`
* SDL2 window flags: `https://wiki.libsdl.org/SDL2/SDL_WindowFlags`
* Khronos OpenGL specification registry: `https://registry.khronos.org/OpenGL/`

The names of commercial platform fighters describe the requested genre only.
No external game assets, source code, sounds or stage layouts were imported.
No fonts are redistributed. Cairo uses the host's ordinary sans-serif font.
